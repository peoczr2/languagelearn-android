# LanguageLearn for Android

Downloads for the LanguageLearn Android app. This repository holds only release files (the APK and the `latest.json` update manifest), no source code.

## Install

1. On your Android phone, open the [latest release](https://github.com/peoczr2/languagelearn-android/releases/latest).
2. Download `LanguageLearn.apk` and open it.
3. The first time, Android asks you to allow installs from your browser. Allow it, then tap Install.

Signing in requires an account with beta access.

## Updates

The app checks this repository's `latest.json` and offers new versions itself: tap "Download update" in the app and confirm the install.
